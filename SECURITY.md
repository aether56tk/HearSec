# Security Policy

## Authorized use only

HearSec is intended for defensive research, documentation, and authorized assessment.

Never use this project to:

- access devices or accounts without permission
- bypass authentication or authorization
- intercept private communications without authorization
- deploy malware or persistence
- extract real patient data

## Reporting security issues

Do not publish sensitive vulnerability details, credentials, or patient information in GitHub issues.

For a real vulnerability affecting a vendor product, follow the vendor's security reporting or coordinated disclosure process.

## Development data

Use synthetic or de-identified data in this repository.
